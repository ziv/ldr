# LDrawJS Projects

## Projects

- JSON version of the LDraw parts library, generated from the official LDraw parts list.
- Binary file format for LDraw files, designed to be self-contained, efficient, and standardized for representing LDraw
  files in a binary form.
- `Three.js` loader for LDraw files, allowing for direct loading of LDraw files in the browser without the need for a
  server or conversion to other formats.

### Loader

A new loader for `Three.js` to load LDraw files directly in the browser, without the need for a server or conversion to
other formats. The loader will support both the official LDraw parts library and user-created models, allowing for a
wide range of applications such as online LEGO building tools, educational resources, and interactive 3D visualizations.
